# 버전 올리기 전 전체 검사 (매번 전부)

`bash tools/check.sh` 를 돌리고 **전부 ✅** 일 때만 올린다.

1. 단위 검사 전부 — 콜 읽기(로지·콜마너·카카오·I-Driver·T맵), 목록/운행내역 화면 무시, 운행일지 데이터 보호(삭제→휴지통, 백업, 자동 청소가 일지를 안 지움), 기본 설정(출근 전 = 퇴근 상태, 수락 콜 바로 일지), 내장 키
2. 화면 모음 `app/build/check/screens.png` 을 **한 장씩 눈으로** 확인 — 글자 깨짐, 줄바꿈, 버튼 정렬, 숫자
3. 콜 상세 지도 — 기본 지도 / 잘못된 키면 기본 지도로 / 카카오 지도 + 핀
4. 카카오 주소 찾기 (가게 이름)
5. APK 빌드 → download/ 복사 → 커밋·푸시 → 다운로드 링크 크기 확인

바뀐 기능은 그 기능 검사를 **먼저 추가**하고 위 전체를 돌린다.
